# SemAder: Evading LLM-Based Binary Code Analysis via Structure-Semantics Joint Induction

> 2026

원문: ACM TOPS, 2026

### Contribution
- 기능을 보존하면서 LLM의 바이너리 분석을 오도하는 적대적 바이너리를 생성하는 구조-의미 결합 유도 프레임워크를 제안합니다.
- LLM 기반 역공학에 맞서 소프트웨어 지식재산을 보호한다는 방어적 동기에서 출발합니다.

> 2026

원문: IEEE TDSC, 2026

### Contribution

### Evaluation
- (초록 기준 정리입니다. 전문을 확보하지 못해 데이터셋과 수치는 확인하지 못했습니다.)
