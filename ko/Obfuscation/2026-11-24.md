# BinXSight: Fast Binary Program Summarization via Hierarchical Modular Decomposition
> arXiv 프리프린트 (심사 전, ACM 저널 양식의 투고본으로 보임). 상하이커지 대학교(ShanghaiTech University), 저장 대학교, 텐센트 Keen Lab, 글래스고 대학교
> 2026

심볼이 제거된 바이너리를 역공학할 때 분석가는 수천 개 함수를 일일이 보지 않고 프로그램 전체가 무엇을 하는지 빨리 파악하고 싶어 합니다. 그러나 기존 LLM 기반 바이너리 요약 연구는 대부분 함수 단위에 머물러, 함수 간 상호작용과 호출 문맥을 놓치고 프로그램 수준 요약으로 합치기 어렵습니다. 저자들은 바이너리를 네 가지 그래프로 이뤄진 "바이너리 그래프"로 표현하고, 이를 기능 모듈 단위로 계층적으로 나눈 뒤 중요한 모듈만 골라 요약하고, 모듈 요약을 맵리듀스 방식으로 합쳐 프로그램 요약을 만드는 BinXSight를 제안했습니다.

### Contribution
- 호출 관계에 그치지 않고 여러 관점의 의존성을 담은 바이너리 표현(바이너리 그래프)을 설계했습니다.
- 소프트웨어 모듈 설계 원칙(높은 응집도, 낮은 결합도)에 기대어 함수를 모듈로 묶고, 오류 처리처럼 핵심 동작이 아닌 모듈은 걸러 내 속도와 품질을 함께 잡았습니다.
- 정상 프로그램뿐 아니라 gh0st, Mirai, WannaCry 계열 등 악성코드를 포함해 평가하고, 최신 악성코드 사례 분석으로 실무 활용성을 보였습니다.

### Evaluation
- 데이터: C/C++ 프로젝트 92개에서 만든 바이너리 110개(네트워크, 원격 제어 악성코드, 랜섬웨어 등). 다른 용도의 데이터와 테스트 데이터가 겹치지 않도록 정규화한 소스 코드 해시로 중복 함수를 걸러 냈습니다.
- 비교 대상: 함수 요약 후 합치기(func-sum), 여기에 최신 함수 요약 기법 MiSum을 넣은 변형, 의사 코드를 한 번에 넣기(func-code), SymGen으로 함수 이름을 예측한 뒤 합치기(sym-sum), Malsight. 기존 기법이 모두 함수 단위라 저자들이 프로그램 수준으로 바꿔 구현했고, 기본 LLM은 gpt-5.4로 통일했습니다.
- 지표와 결과: 임베딩 유사도(SIMILARITY) 0.6137로 기준선보다 23.18~46.99% 높았고, BLEU, ROUGE-L, METEOR도 모두 앞섰습니다. 저자들은 여러 지표의 사람 평가 상관도를 먼저 확인해 임베딩 유사도를 주 지표로 골랐습니다. 함수 약 3,429개짜리 바이너리를 평균 24.3초에, 함수 59,173개짜리도 3.8분에 처리했고, 전체 API 비용은 78.1달러였습니다.
- 사용자 연구: 7년 이상 경력의 역공학 실무자 15명과 보안 전공 박사과정생 12명이 BinXSight와 최고 기준선의 요약을 무작위 순서로 비교했고, 기관 심의(IRB) 승인을 받았다고 밝혔습니다.
- 난독화 영향: 40개 프로젝트를 Obfuscator-LLVM의 명령 치환(SUB), 가짜 제어 흐름(BCF), 제어 흐름 평탄화(FLA), 전부 적용(ALL)으로 난독화했을 때 네 지표가 모두 떨어졌고, BCF·FLA·ALL에서 하락이 더 컸습니다. 그래도 모든 설정에서 기준선보다는 나았다고 합니다.
- 신빙성: 기준선을 저자들이 직접 바꿔 구현했으므로 원래 기법의 최선 성능과는 다를 수 있고, 주 지표가 임베딩 모델 기반 유사도라는 한계가 있습니다. 개선 폭은 20~40%대로 지나치게 크지 않습니다.

#### Comment
- 난독화 관점에서는 "LLM 기반 프로그램 수준 역공학이 O-LLVM 난독화에 얼마나 버티는가"에 대한 정량 자료가 들어 있다는 점이 쓸모 있습니다. 저자들은 난독화 해제는 범위 밖이라고 했고, 패킹된 바이너리는 정적 분석 한계로 다루지 못한다고 밝혔습니다. 보호 기법 설계 쪽에서는 SUB 같은 약한 난독화만으로도 요약 품질이 떨어진다는 결과가 참고가 됩니다.
- 중국 기관(상하이커지 대학교, 저장 대학교, 텐센트 Keen Lab) 논문이라 검증을 더 했습니다. 저자 연락처가 모두 기관 도메인으로 적혀 있고 영국 글래스고 대학교 교신 저자가 함께 있습니다. Zenodo 아티팩트 주소를 제시해 재현 경로가 있고, 평가 지표 선택 근거와 사용자 연구 절차를 밝혔으며, 수치도 과도하지 않아 싣기로 했습니다. 다만 양식상 게재처 정보가 비어 있는 투고본입니다.
