# A Model Obfuscation and Controllable Authorization Scheme for Deep Learning as a Service
> arXiv 프리프린트 (심사 전). 베이징 사범대학교 인공지능학원, 홍콩 시티대학교
> 2026

딥러닝 모델이 엣지 기기나 제3자 기기에 직접 배포되면 역공학으로 가중치와 구조가 빠져나갈 위험이 커집니다. 기존 모델 보호는 전용 하드웨어(TEE 등)나 큰 계산 비용(동형 암호 등)에 기대거나, 보호는 하더라도 "누가 모델을 쓸 수 있는가"를 통제하지 못했습니다. 저자들은 모델 난독화로 파라미터와 구조를 숨기면서, 난독화된 파라미터를 원래 값으로 되돌리는 보정 단계를 사용자 키에 묶어 인증된 사용자만 올바르게 추론할 수 있게 하는 KeyObf를 제안했습니다. 선택한 층의 출력에 스케일 인자와 키에서 유도한 인자를 곱하는 결합 변환을 넣고, 추론 라이브러리가 사용자 키, 사용자 식별자, 인증 자격 증명으로 이 인자를 복원해 보정합니다.

### Contribution
- 모델 난독화와 사용 권한 통제를 하나의 구조로 합쳤습니다. 인증을 우회하더라도 키에서 나오는 보정 인자가 없으면 올바른 출력을 낼 수 없게 했습니다.
- 키 인자를 HMAC-SHA256으로 결정적으로 유도하고 출력 특징(합성곱 층에서는 출력 채널)마다 독립 인자를 붙였으며, 채널 묶음 단위에 따라 키 인자 복원이 얼마나 쉬워지는지 비교했습니다.
- 결합 변환을 넣은 뒤 보정하면 원래 모델의 출력이 복원된다는 점을 정리로 제시했습니다.
- 전용 하드웨어 없이 TFLite 모델 형태로 동작합니다.

### Evaluation
- 대상: VGG11, MobileNetV2, ResNet20/32/44/56 여섯 모델을 CIFAR-100에서 평가했습니다. 모델마다 결합 위치 10곳을 두었습니다.
- 정확도와 비용: 올바른 키와 자격 증명이 있으면 Top-1 정확도 변화가 평균 -0.01%포인트(71.39% → 71.38%)였습니다. 테스트 1만 장 기준 평균 추론 시간은 208.65ms에서 391.31ms로 약 1.9배 늘었고, ResNet56은 293.66ms에서 632.77ms로 늘었습니다.
- 권한 통제: 잘못된 키나 자격 증명이 없으면 추론 라이브러리가 인증 단계에서 거부했습니다. 인증을 통제된 조건에서 우회했을 때, 키 결합이 없는 변형은 정상 추론이 됐지만 KeyObf는 올바르게 보정하지 못했습니다.
- 역공학 저항: 동적 계측 도구 DLModelExplorer로 가중치 추출률을 쟀더니 KeyObf 48.9%, 기존 방법 DynaMO 51.6%로 비슷했습니다. 비교 대상은 ModelObfuscator와 DynaMO입니다.
- 신빙성: 비교 대상은 같은 문제를 다룬 공개 연구라 적절하지만, 평가가 CIFAR-100의 소형 모델에 한정되고 대형 모델이나 실제 모바일 기기 측정은 없습니다. 가중치 추출률이 절반가량 남는다는 결과에서 보듯, 이 방식은 추출 자체를 막기보다 "추출한 가중치로 올바른 추론을 하지 못하게" 하는 데 무게가 있습니다.

#### Comment
- 앱에 내장한 온디바이스 모델을 보호하고 라이선스 키로 사용을 제한하려는 실무 수요와 맞닿아 있습니다. 다만 키 인자가 사용자 기기에서 복원되는 구조이므로, 인증된 사용자가 자신의 키로 보정된 가중치를 메모리에서 덤프하는 공격에는 근본적으로 대응하지 못합니다. 본문에서 이 위협을 별도로 평가하지는 않았습니다.
- 중국 기관 논문이라 검증을 더 했습니다. 교신 저자 중 Xiaohua Jia는 홍콩 시티대학교 교수로 연구실 홈페이지와 이력서가 공개되어 있어 실재가 확인됩니다. 결과 수치가 지나치게 좋지 않고(추론 시간 증가, 추출률 48.9%를 그대로 보고), 비교 대상도 같은 문제를 다룬 선행 연구입니다. 반면 코드 공개 주소가 없고 게재처도 정해지지 않아 재현성은 확인하지 못했습니다.
