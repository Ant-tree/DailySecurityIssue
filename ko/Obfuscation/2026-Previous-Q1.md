# From Obfuscated to Obvious: A Comprehensive JavaScript Deobfuscation Tool for Security Analysis
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

악성 자바스크립트는 문자열 인코딩, 함수명 뒤섞기, 분석 방해 같은 다층 난독화로 정적 분석을 회피합니다. 기존 역난독화 도구는 입력 형식이 다양하면 처리하지 못하거나 특정 난독화 유형만 다루고, 결과도 읽기 어렵게 내놓습니다. JSIMPLIFIER는 전처리, 추상 구문 트리 기반 정적 분석, 동적 실행 추적, LLM 기반 식별자 재명명을 잇는 다단계 파이프라인으로 이 문제를 해결하려는 역난독화 도구입니다. 저자들은 실제 악성 23,212개와 정상 21,209개로 이뤄진 4만 4천여 개 규모의 공개 데이터셋도 함께 내놓았습니다.

원문: https://www.ndss-symposium.org/ndss-paper/from-obfuscated-to-obvious-a-comprehensive-javascript-deobfuscation-tool-for-security-analysis/

### Contribution
- 정적 AST 분석과 통제된 실행이라는 두 전략에 LLM 기반 의미 보강을 더해, 읽기 쉬운 코드 복원을 목표로 한 종합 역난독화 도구를 만들었습니다.
- 제어 흐름과 데이터 흐름, 코드 단순화 정도, 엔트로피, LLM 기반 가독성을 묶은 다차원 평가 지표를 제안했습니다.
- 실제 환경 난독화 자바스크립트로는 가장 큰 규모의 데이터셋을 구축해 공개했습니다.

### Evaluation
- 20가지 난독화 기법에 대해 100% 처리 가능, 평가 부분집합에서 100% 구문 정확성, Halstead 복잡도 88.2% 감소, LLM 다수가 검증한 4배 이상 가독성 향상을 보고합니다.
- 의미 일관성은 83%로, GPT(74.29%)나 기존 도구 JST(55.32%)보다 높았습니다. LLM 실험에는 GPT-4o-mini 기준 약 480~500달러의 API 비용이 들며, AST 전용 모드로도 핵심 주장은 검증 가능하다고 밝힙니다.
- 100% 처리 가능은 "처리 실패가 없다"는 뜻이고 복원 정확성은 수작업 검증된 부분집합 기준이므로, 전체 복원 품질을 100%로 읽어서는 안 됩니다.

#### Comment
- 자바스크립트 난독화 도구를 만드는 입장에서는, 공개된 대규모 데이터셋과 다차원 평가 지표 자체가 역난독화 연구의 벤치마크로 바로 활용할 만합니다.
- 중국 기관 검증: 베이징우전대와 치안신(QI-ANXIN) 기술연구소 공동 연구입니다. 코드와 데이터셋이 Zenodo 및 GitHub에 공개돼 재현 가능하고, 평가 지표와 비용을 투명하게 밝히며 수치를 과장 없이 제시해 포함했습니다. 치안신은 중국의 주요 보안 기업으로 실재가 분명합니다.

# WBSLT: A Framework for White-Box Encryption Based on Substitution-Linear Transformation Ciphers
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

화이트박스 위협 모델은 공격자가 암호 구현과 실행 환경을 완전히 장악한 상황을 가정하며, IoT 기기처럼 관리되지 않는 환경이 여기에 해당합니다. 기존 화이트박스 암호 설계는 주로 키에 의존하는 테이블 하나만 보호해, 화이트박스 공격과 부채널 공격으로 키가 복원되곤 했습니다. WBSLT는 AES, SERPENT 같은 치환-선형변환(SLT) 계열 블록 암호의 테이블화 화이트박스 구현을 위한 설계 프레임워크로, 각 구성 요소의 연산 일부를 다음 요소에 넘겨 테이블 경계를 흐리게 만들어 단일 테이블 공격을 막습니다. 마스킹, 셔플링, 외부 인코딩을 더해 차분 연산 분석과 차분 오류 분석에도 대응합니다.

원문: https://www.ndss-symposium.org/ndss-paper/wbslt-a-framework-for-white-box-encryption-based-on-substitution-linear-transformation-ciphers/

### Contribution
- 임의의 SLT 암호에 적용 가능한 화이트박스 구현 설계 프레임워크를 제안하고, 구성 요소 경계를 흐리는 방식으로 대수적 분석 공격을 방어합니다.
- unbreakability와 one-wayness라는 두 보안 정의 아래 종합 보안 분석을 수행하고, 기존 기법이 달성하지 못한 unbreakability를 달성한다고 주장합니다.
- 라운드 간 흐림 정도를 재는 새 보안 지표(distinguishable SA-structure number)를 제안했습니다.

### Evaluation
- 고성능 플랫폼 4종과 자원 제약 플랫폼 4종(라즈베리파이, 스마트폰 포함)에서 암호화 속도와 메모리, 에너지를 측정했습니다. 최적화 WB-AES는 23개 인기 IoT 게이트웨이 중 20개(86.96%)에 배포 가능했습니다.
- IDDHO-DCA 공격 성공률이 방어 적용 전 100%에서 적용 후 0.40%로 떨어져 사실상 무작위 추측 수준이 됐습니다. 기존 Chow 등의 WB-AES와 비슷한 성능을 내면서 보안은 더 높다고 비교합니다.
- 전통 AES 대비 저장 공간 과부하가 있고, 보안 주장의 상당 부분이 이론적 분석에 기대므로 독립적 암호 분석 검증이 추가로 필요합니다.

#### Comment
- 바이너리 하드닝과 화이트박스 암호를 다루는 입장에서, 단일 키 의존 테이블 보호의 한계와 경계 흐림이라는 설계 아이디어가 직접적인 참고가 됩니다.
- 중국 기관 검증: 퉁지대 연구진의 논문으로, 코드가 GitHub와 Zenodo에 공개돼 있습니다. 화이트박스 암호는 공개 후 깨지는 사례가 많아 unbreakability 주장은 신중히 봐야 하지만, 공격 성공률 감소를 실측으로 제시하고 구현을 공개해 재현과 반증이 가능하므로 포함했습니다.

#### Comment
- 난독화 도구를 만드는 입장에서, 난독화의 보호력을 복잡도 지표가 아니라 실제 이해 지연으로 평가해야 한다는 문제 제기가 실무적으로 유용합니다. 지표만으로 보호 강도를 주장하기 어렵다는 근거가 됩니다.
