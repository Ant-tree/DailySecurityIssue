# E-UDE: A Scientific Machine Learning Model for Malware Propagation Dynamics
> arXiv cs.CR 2611.00971 (프리프린트, 심사 전). 라지브 간디 공과대학교(RGPV), 인도 과학산업연구위원회 국립데이터과학AI연구소(CSIR, 인도)
> 2026

인터넷에서 악성코드가 퍼지는 양상을 예측하는 모델은 크게 두 갈래입니다. 미분방정식 기반의 전염병형 모델은 해석은 쉽지만 실제 데이터와 잘 맞지 않고, 신경망 기반 모델은 잘 맞추지만 왜 그런지 설명하기 어렵습니다. 범용 미분방정식(Universal Differential Equation) 방식은 두 접근을 섞어, 알려진 메커니즘은 방정식으로 쓰고 설명되지 않는 부분은 신경망 잔차로 학습합니다. 이 논문은 기존 UDE 악성코드 모델을 확장해 감염 가능, 감염, 대응, 혼잡의 네 상태를 별도 구획으로 두고 전파율, 네트워크 구조, 혼잡 효과, 외부 공격 유입, 방어 대응, 보안 수준 저하를 명시적으로 넣은 E-UDE(Enhanced UDE)를 제안합니다. 구획이 명시되어 있어, 방어 대응 속도를 바꾸면 확산이 어떻게 달라지는지 같은 시나리오 분석을 할 수 있다는 점을 장점으로 내세웁니다.

### Contribution
- 기존 UDE 모델의 일반적인 성장 항 대신 네 가지 상태 구획과 방어, 혼잡 요인을 넣어 해석 가능성을 높였습니다.
- 학습된 매개변수로 방어 대응 강화, 외부 유입 차단 같은 개입 시나리오의 효과와 비용 효율을 비교하는 분석 틀을 보였습니다.
- 데이터에 잡음을 섞었을 때 예측 성능이 덜 떨어진다는 견고성 결과를 함께 제시했습니다.

### Evaluation
- 데이터: CAIDA가 공개한 Code Red 웜(2001년)과 Witty 웜(2004년) 감염 호스트 관측 자료.
- 비교 대상: 고전적인 미분방정식 모델, 신경망 미분방정식(Neural ODE), 기존 UDE.
- 결과(Code Red 전체 구간 적합): E-UDE의 RMSE 783.70, MAE 421.65, MAPE 13.36%, 상관계수 0.961로, 고전 모델(RMSE 2325.87), Neural ODE(2094.76), UDE(1281.84)보다 낮은 오차를 보였습니다. 앞쪽 25%로 학습하고 뒤쪽 75%를 예측한 시간순 분할에서도 시험 RMSE 634.6, 상관계수 0.964를 보고합니다.
- 지표의 신빙성: 비교 대상이 모두 같은 계열의 단순한 모델이고, ARIMA나 LSTM 같은 시계열 예측 기준선은 표에 없습니다. 무엇보다 20년 넘은 단일 웜 확산 곡선 두 개로만 평가했기 때문에, 오늘날의 랜섬웨어나 봇넷처럼 표적이 좁고 사람이 개입하는 확산에 그대로 적용된다고 보기는 어렵습니다.

#### Comment
- 보안 쪽보다는 과학적 기계학습(물리 법칙과 신경망 결합)의 응용 사례로 읽는 편이 적절합니다. 대응 속도나 혼잡 같은 요인을 구획으로 드러낸 점은 교육용이나 정책 시뮬레이션에 쓸모가 있습니다.
- 한계: 구획 수가 늘면 매개변수도 늘어 과적합 위험이 있는데, 관측 자료가 감염 호스트 수 하나뿐이라 숨은 상태(대응, 혼잡)가 실제로 식별되는지는 따로 검증하지 않았습니다. 코드 공개 여부는 본문에서 확인하지 못했습니다.
- 신뢰도: 인도 국책 연구소와 대학 연구진의 심사 전 원고입니다. 공개 데이터셋을 쓰고 설정 표를 제시해 재현은 비교적 쉬운 편입니다.
