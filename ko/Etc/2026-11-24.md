# Exploring Early Vulnerability Analysis via Automatic Identification of Vulnerability-Introducing Commits
> ACSAC 2026(제42회 Annual Computer Security Applications Conference) 채택, arXiv 등록. 텍사스 대학교 댈러스, 팔로알토 네트웍스
> 2026

취약점 데이터셋은 보통 취약점 수정 커밋(VFC) 바로 앞 코드만 취약하다고 표시합니다. 그래서 취약점이 처음 들어온 시점부터 수정되기 전까지의 중간 버전은 빠지고, 탐지 모델이 잠복 단계의 취약점을 찾을 수 있는지도 알 수 없습니다. 저자들은 취약점 유입 커밋(VIC)을 수작업으로 주석한 데이터셋 세 개를 만들고, 보안 수정 패턴과 데이터 상태 분석으로 수정이 함축한 취약점 의미를 복원해 VIC를 찾는 D-SZZ를 제안했습니다. 이 도구로 NVD의 영향 버전 기록 오류 16건을 찾아 모두 공식 수정받았습니다.

원문 링크:
- arXiv 초록: https://arxiv.org/abs/2611.26739
- arXiv HTML 본문: https://arxiv.org/html/2611.26739
- arXiv PDF: https://arxiv.org/pdf/2611.26739
- ACSAC 2026 채택 논문 목록: https://www.acsac.org/2026/program/papers/
- 저자 저장소(구현): https://github.com/XSecLab-UTD/D-SZZ

### Contribution
- 기존 SZZ 계열은 수정 커밋의 삭제된 줄만 거슬러 올라가 보안 검사 추가처럼 "더하기만 한" 수정을 다루지 못했습니다. D-SZZ는 수정 전후 코드 속성 그래프(CPG)를 만들고, 보안 수정 패턴으로 관련 문장을 골라낸 뒤, 데이터·제어 흐름으로 수정과 인과적으로 얽힌 수정 전 데이터 상태를 찾아 저장소 이력을 거슬러 올라갑니다.
- 최근 NVD 기록과 tcpdump, Vim에서 수작업 주석한 C/C++ VIC 783건을 공개 데이터셋으로 만들었습니다.
- 잠복 단계 취약점 샘플을 학습에 넣으면 탐지 모델 성능이 좋아진다는 점을 보였습니다.

### Evaluation
- 비교 대상: SZZ, V-SZZ, Sem-SZZ, LLM4SZZ, Vercation, LLMBisect를 원 논문의 아티팩트로 실행했습니다.
- 결과: 최고 기준선 V-SZZ보다 재현율이 세 데이터셋과 외부 Linux 데이터셋에서 각각 13.64%, 8.91%, 10.40%, 6.63% 높았고, F1은 6.70~11.93% 높았습니다. 영향 버전 식별에서는 두 오픈소스 데이터셋에서 F1 94.42%, 94.74%였습니다.
- 탐지 모델: Devign, Reveal, LineVul, VulBERTa, CodeBERT, PDBERT를 평가했는데, 수정 직전 코드로만 학습한 모델은 처음 유입된 형태의 취약점을 잘 찾지 못했고, 초기 단계 샘플을 더하면 두 경우 모두 좋아졌습니다.
- 비용: NVD 기반 VFC 5,993건에서 VIC 5,107건을 23.7시간에 찾았고(VFC당 평균 14.24초), LLM 기반 기준선은 VFC당 7만~72만 토큰을 썼습니다.
- 신빙성: 기준선을 원 아티팩트로 돌렸고 외부 데이터셋 결과와 NVD 공식 수정이라는 외부 검증이 있습니다. 다만 NVD 신규 데이터셋 기준 정밀도는 28.78%, F1은 41.24%로 절대 수준이 높지 않아, 자동으로 뽑은 VIC를 그대로 학습 데이터로 쓰기에는 잡음이 적지 않습니다.

#### Comment
- 심사를 거친 ACSAC 2026 채택 논문입니다. 취약점 탐지 연구의 데이터 구성 관행을 다시 생각하게 하는 결과이며, 영향 버전 정보가 중요한 공급망 보안(SBOM, SCA) 쪽에도 바로 쓸 수 있습니다.
- 본문 출처: arXiv PDF(사용자 컴퓨터에서 받음).

# "More Than You Expect!": Leakage-Abuse Attacks on Encrypted Vector Search
> arXiv 프리프린트 (심사 전). 난카이 대학교(Nankai University)
> 2026

벡터 데이터베이스는 의미 검색과 RAG에 쓰이는데, 임베딩, 질의, 레코드 라벨에 민감 정보가 담길 수 있어 암호화된 벡터 검색 기법이 나오고 있습니다. 그런데 효율을 위해 어떤 레코드가 반환됐는지(접근 패턴)는 숨기지 않는 기법이 많습니다. 저자들은 질의마다 함께 반환되는 레코드 관계만으로 암호화된 레코드와 질의의 의미 범주를 추론할 수 있다는 "의미 이웃 누설"을 정의하고, 이를 이용하는 수동적 누설 악용 공격 SAGE를 제안했습니다. 공동 반환 관계로 가중 그래프를 만든 뒤, 클래스 비율만 아는 경우(SAGE-Dist)와 일부 레코드 라벨을 아는 경우(SAGE-Known)의 두 변형으로 라벨을 추론합니다.

원문 링크:
- arXiv 초록: https://arxiv.org/abs/2611.27174
- arXiv HTML 본문: https://arxiv.org/html/2611.27174
- arXiv PDF: https://arxiv.org/pdf/2611.27174

### Contribution
- 기존 누설 악용 공격은 1차원 정렬 순서나 키워드 빈도에 기대는데, 고차원 top-k 검색에는 전역 순서가 없어 그대로 적용할 수 없다는 점을 짚고, 의미 범주 추론이라는 새 목표를 세웠습니다.
- SAGE-Dist는 스펙트럴 그룹을 추정 클래스 비율과 맞춘 뒤 최적 수송으로 다듬고, SAGE-Known은 그래프 라벨 전파와 앵커 투표를 결합합니다.
- 실제 오픈소스 암호화 벡터 데이터베이스 Quiver와 거리 비교 보존 암호(DCPE)에서도 누설이 남는다는 점을 보였습니다.

### Evaluation
- 데이터: AG News(4개 범주), Yahoo Answers(10), MedMCQA(21), CIFAR-100(100). 텍스트는 BGE-base-en-v1.5, 이미지는 OpenCLIP ViT-B/32 임베딩을 쓰고, 질의 2,000개, k=100으로 관찰했습니다.
- 결과: 레코드 라벨 1%만 알아도 SAGE-Known은 최대 84.3%의 레코드 라벨 정확도를 보였고 네 데이터셋 모두에서 가장 강한 기준선을 앞섰습니다. SAGE-Dist는 AG News에서 레코드 66.9%, 질의 범주 68.1%로 기준선보다 각각 21.8%p, 41.9%p 높았지만, 데이터셋에 따라 편차가 컸습니다.
- 실제 시스템: Quiver의 DCPE(β=1.6)에서 검색 재현율이 68.8~76.9%로 떨어져도 SAGE-Known은 84.2%, 64.7%, 46.9%, 27.1%를 유지했습니다. 반면 SAGE-Dist는 61.7%, 32.8%, 5.4%, 1.9%로 범주가 많은 데이터셋에서 거의 무력했습니다.
- 신빙성: 공개 데이터셋과 공개 구현을 쓰고 열 번 반복 평균을 보고했으며, 약한 결과(MedMCQA, CIFAR-100의 SAGE-Dist)도 숨기지 않았습니다. 다만 질의를 데이터베이스와 무관하게 균등 추출한 설정이라 실제 질의 분포에서는 결과가 달라질 수 있습니다.

#### Comment
- 암호화 RAG나 프라이버시 보호 벡터 검색을 설계할 때 "임베딩만 암호화하면 된다"는 가정이 부족하다는 점을 보여 줍니다. 접근 패턴 은닉 비용과 누설 사이의 절충을 따져야 합니다.
- 중국 기관(난카이 대학교) 논문이라 검증을 더 했습니다. 같은 연구진이 IEEE S&P 2026에 암호화 SQL 추론 공격 논문을 낸 실적이 참고 문헌으로 확인되고, 저자 연락처도 기관 도메인입니다. 실험 대상인 Quiver와 DCPE는 외부 공개 구현이라 재현 경로가 있지만, 저자 코드 공개 주소는 본문에서 찾지 못했습니다. 수치가 과도하지 않고 약한 결과도 함께 보고해 싣기로 했습니다.
- 본문 출처: arXiv PDF(사용자 컴퓨터에서 받음).

# Felid: A Flexible and Efficient Design for Transformer Fine-Tuning over Encrypted Data
> NeurIPS 2026 구두 발표(Oral) 채택 표시, arXiv 프리프린트. 초록 기반 요약, 본문 미확인
> 2026

완전 동형 암호(FHE)를 쓰면 민감한 데이터를 노출하지 않고 트랜스포머를 미세 조정할 수 있지만, 암호문 연산 비용이 커서 구조 개선만으로는 한계가 있다고 저자들은 설명합니다. 이들은 병목을 암호문 연산 수준에서 공략해, 입력 개수를 유연하게 묶는 새 패킹 방식, 연산별 행렬 계산 알고리즘(회전, 재선형화, 부트스트래핑 횟수 감소), 원소별 활성 함수를 부트스트래핑 단계에 합치는 함수형 부트스트래핑 활용을 제안했다고 밝혔습니다.

원문 링크:
- arXiv 초록: https://arxiv.org/abs/2611.27175
- arXiv HTML 본문: https://arxiv.org/html/2611.27175
- arXiv PDF: https://arxiv.org/pdf/2611.27175

### Contribution
- 저자들에 따르면, 미세 조정 작업에 맞게 배치 크기를 유연하게 조절할 수 있는 패킹 방식을 설계했습니다.
- 행렬 연산마다 전용 알고리즘을 둬 암호문 회전과 재선형화, 부트스트래핑 호출을 줄였다고 합니다.
- 함수형 부트스트래핑으로 활성 함수 계산을 부트스트래핑에 접어 넣어 전체 계산량을 줄였다고 주장합니다.

### Evaluation
- 초록에 적힌 수치: 최신 기법 대비 모든 행렬 연산에서 암호문 회전과 재선형화 30배 감소, 전체 계산 흐름에서 부트스트래핑 호출 2.5배 감소. 2층 BERT 계열 모델을 배치 크기 16으로 미세 조정하는 데 650초가 걸려 최신 기법보다 8배 빠르다고 합니다.
- 본문을 읽지 못해 데이터셋, 비교 조건, 지표의 신빙성은 확인하지 못했다.
