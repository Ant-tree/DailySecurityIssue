# Small Leaks Sink Great Ships: Automated Analysis of Protocols That Tolerate Low-Entropy Keys
> NDSS 2027 채택(DOI 10.14722/ndss.2027.230474), arXiv 등록. 우한 대학교, 산둥 대학교
> 2026

WPA2-PSK, 블루투스 저전력(BLE), 블루투스 클래식(BC)은 사용 편의성, 하위 호환성, 자원 제약 때문에 엔트로피가 낮은 키를 허용합니다. 그런데 ProVerif나 TAMARIN 같은 기호 프로토콜 검증 도구는 "완벽한 암호화"를 가정하므로 무차별 대입 공격자를 다룰 수 없고, 기존 연구는 프로토콜마다 "이 키는 공격자에게 드러난다"는 규칙을 손으로 넣어 왔습니다. 저자들은 프로토콜에 묶이지 않는 자동화된 기호 분석 방법을 제안했습니다. 무차별 대입의 전제 조건을 함수 기호와 무관하게 표현하는 메시지 유도 사실 MDerive, 값 깨기, 관계 깨기, 메시지 유도의 세 층으로 된 깨기 오라클, 공격자가 소진할 수 있는 키 길이를 비트 단위로 제한하는 공격자 모델이 핵심입니다. 이를 TAMARIN 커널을 고치지 않는 문법 확장 도구 EntropyVerif로 구현했고, 이 도구로 블루투스 클래식의 새로운 프로토콜 수준 공격을 찾았습니다.

### Contribution
- 완벽한 암호화 가정을 완화하고 복합 키의 재귀적 분해를 지원하는, 프로토콜과 무관한 저엔트로피 키 분석 방법론을 제시했습니다.
- 사용자가 저엔트로피 항에 `:= L` 표시만 붙이면 표준 다중집합 재작성 규칙을 생성하는 EntropyVerif를 만들어, 모든 증명을 수정하지 않은 TAMARIN이 수행하게 했습니다.
- PMKID 공격(WPA2-PSK), KNOB 공격과 방식 혼동(Method Confusion) 공격(BLE 페어링)을 프로토콜별 규칙 없이 자동으로 재발견했습니다.
- 블루투스 클래식에서 한쪽 기기의 세션 키 길이를 반복해서 낮추고 얻은 키 조각을 다시 조합하는 단방향 다중 하향(UMD) 공격을 새로 찾았습니다. 최대 128비트 키를 쓰는 기기에 대해 키 복구 비용을 2^128에서 n·2^(128/n)으로, n=16이면 2^12까지 낮춥니다.

### Evaluation
- 대상: WPA2-PSK, BLE 페어링, BC 세션 수립 프로토콜과 여섯 가지 BC 기기 구성(보안 연결 전용, 레거시 전용 등 기기가 받아들이는 키 길이 조합). AMD 7950X3D, 192GB RAM 서버에서 TAMARIN을 백엔드로 썼습니다.
- 결과: 기존 모델과 비교해 WPA2-PSK에서는 KRACK을 그대로 찾으면서 기존 분석에서 드러나지 않던 PMKID 공격도 찾았고, BLE에서는 KNOB와 방식 혼동 공격을 모두 찾았습니다. BC에서는 주변 기기가 허용하는 최소 키 길이가 공격자 능력 범위 안이면 세션 키가 반드시 노출되고, 레거시 호환 기기는 반복 하향으로 가장 긴 세션 키까지 복구된다는 결과를 얻었습니다.
- 비용: 공격이 없는 알리페이 결제 프로토콜 모델 세 개에 적용했을 때 판정과 증명 단계 수는 그대로였고, 실행 시간은 약 12초(실행 시간의 9% 미만)에서 약 4분 늘었습니다. 반면 가장 무거운 BC 구성은 약 9.9×10^4초가 걸렸고, BC와 BLE 모델은 손으로 쓴 TAMARIN 전술(tactic)에 의존합니다.
- 신빙성: 모든 분석은 기호 모델 안에서 이뤄졌고, UMD 공격의 발견과 검증에 실제 블루투스 기기는 쓰지 않았다고 저자들이 명시했습니다. 대신 2024년 7월 블루투스 SIG에 신고했고, SIG가 2025년 2월 내부 분석 결과 이 시나리오를 실제로 가능하다고 본다고 회신했다고 적었습니다.

#### Comment
- 중국 기관 논문이라 추가로 확인했습니다. 게재처는 보안 분야 최상위 학회인 NDSS 2027이고 본문에 NDSS DOI가 인쇄되어 있습니다. 도구 저장소(luojiazhishu/entropy-verif)가 실제로 존재함을 확인했고, 결과는 공개된 TAMARIN 모델로 재현할 수 있는 기호 분석이라 평가 지표가 부풀려질 여지가 적습니다. 비교 대상도 같은 프로토콜의 기존 문헌 모델로 적절합니다.
- UMD는 특정 제품의 구현 버그가 아니라 BC 규격이 키 길이 재협상을 허용하는 방식의 설계 약점이라는 점에서, 레거시 호환 블루투스 기기(차량, 오디오 기기 등)에 오래 남을 수 있는 문제입니다. 실제 기기에서의 시연은 없으므로 실전 난이도는 별도로 봐야 합니다.

# Make the Adversary Spend More: Stateful Deception as a Cost-Exchange Primitive for AI-Era Cyber Defense
> 5th Workshop on Active Defense and Deception(AD&D, ESORICS 2026 공동 개최 워크숍) 게재 예정, arXiv 등록(심사 전 저자 원고). CNIT, 볼로냐 대학교, 노스캐롤라이나 대학교 윌밍턴, 파르마 대학교
> 2026

LLM이 공격자의 탐색과 적응 비용을 낮추는 반면, 방어자는 무한정 연산을 쓰고 싶은 유혹에 빠집니다. 저자들은 사이버 디셉션을 사실감이나 탐지율이 아니라 공격자와 방어자 사이에 만들어 내는 "비용 교환"으로 평가해야 하고, 그 교환을 유리하게 만드는 핵심 요소는 공격자별로 유지되는 지속 상태라고 주장합니다. 세션마다 초기화되거나 여러 공격자의 세션이 섞이는 허니팟 대신, 인식된 공격자마다 자신이 장악했다고 믿는 환경에 과거 행동과 일관되게 다시 들어오도록 하고, LLM은 상태를 저장하지 않고 명시적 상태를 그려 주는 역할만 맡깁니다. 이 교환을 공격자가 소모한 임무 가중 노력과 방어자가 쓴 자원의 비율인 디셉션 교환율(DER)로 정형화하고, Cowrie와 로컬 LLM을 결합한 SSH 허니팟으로 구현했습니다.

원문 링크:
- arXiv 초록: https://arxiv.org/abs/2611.34770
- arXiv HTML 본문: https://arxiv.org/html/2611.34770
- arXiv PDF: https://arxiv.org/pdf/2611.34770

### Contribution
- AI 시대 디셉션의 단위는 허니팟 인스턴스가 아니라 공격자별 명시적 상태(파일 시스템, 도구, 자격 증명, 서비스, 상호작용 기록)라는 입장을 제시했습니다.
- 인프라, 공격자별 상태, AI 추론, 에너지, 사람의 감독, 임무 위험을 명시적 항목으로 둔 비교 지표 DER을 제안했습니다.
- 실제 운영 중인 생성형 허니팟에서 DER의 분모(방어자 비용)를 측정하고, 벤치마크와 실제 운영 품질의 차이, 추론형 모델의 사고 과정 노출이라는 두 가지 실패 유형을 보고했습니다.

### Evaluation
- 설정: 공개 가중치 모델 5개(Llama 3.1 8B, Gemma 2 9B-IT, Gemma 4 E4B, Gemma 4 26B-A4B, Qwen 3.6 35B-A3B)를 Cowrie 기반 SSH 허니팟의 응답 생성기로 썼습니다.
- 비용: 결정적 처리 계층(Cowrie 기본 명령), 응답 캐시, 프롬프트 압축 등을 적용해 세션당 토큰이 약 13,134개에서 약 4,855개로 약 63% 줄었고, 모델 호출은 10회에서 4회로, 평균 지연은 약 3초에서 약 1.5초로 줄었습니다.
- 품질: 벤치마크에서 좋은 응답이 약 97%였던 Gemma 4 26B-A4B가 실제 운영에서는 완화 조치 전 약 57%로 떨어졌고, Llama 3.1 8B는 약 95%에서 약 100%로 올랐습니다. Qwen 3.6 35B-A3B는 거의 모든 명령에서 사고 과정을 그대로 출력해 셸 응답으로 쓸 수 없었습니다. 완화 조치 후 Gemma 4 26B-A4B는 13개 명령 운영 시험에서 약 100%로 회복했습니다.
- 신빙성: 저자들이 직접 밝힌 대로 이번 논문은 방어자 쪽 비용만 측정했고, 공격자별 상태 유지와 DER의 분자(공격자 소모 노력)는 명세만 하고 측정하지 않았습니다. 운영 시험 명령 수도 13개로 작습니다.

#### Comment
- MTD와 디셉션 관점에서 "LLM 허니팟은 상태 일관성이 핵심 약점"이라는 기존 관찰을 비용 지표로 정리한 입장 논문에 가깝습니다. 추론형 모델이 사고 과정을 노출해 허니팟임을 스스로 드러낸다는 실무 관찰은 바로 쓸모가 있습니다.
- 워크숍 논문이라 심사 강도는 본 학회보다 낮고, 제안의 핵심인 공격자 쪽 효과는 아직 실증되지 않았습니다. 코드 공개 주소는 본문에서 찾지 못했습니다.

격자 기반 암호는 전자 서명, 암호화부터 완전 동형 암호(FHE)까지 다양한 양자 내성 기법의 기반이 되지만, 격자 연산이 올바르게 수행되었는지 검증하는 비용은 여전히 큽니다. 특히 계산량이 많은 FHE 연산이나 스마트 계약을 통한 온체인 검증처럼 자원이 제한된 환경에서 부담이 큽니다. 저자들은 네가사이클릭(negacyclic) 다항식 연산을 그대로 증명하는 기법 Northstar를 제안했다고 밝힙니다.
