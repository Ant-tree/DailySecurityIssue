# Rented Oscillations: Multi-Tenant Data Center Workload Synchronization Attacks and Mitigation
> arXiv 프리프린트 (심사 전). 본문에 소속 표기 없음(마지막 저자는 KAUST, 사우디아라비아)
> 2026

워크스테이션을 시간 단위로 빌려주는 멀티테넌트 데이터센터는 추론, CPU 작업, 학습이 뒤섞여 전력 수요가 평탄하다고 여겨져 왔습니다. 저자들은 공격자가 위조 신원이나 도용한 결제 수단으로 여러 계정을 만들어 같은 지역의 GPU를 대량으로 빌린 뒤, 일부러 최적화하지 않은 LLM 학습을 돌려 계산과 대기 구간이 번갈아 나타나는 사각파 전력 패턴을 서로 맞추는 공격을 제시했습니다. 개별 작업은 비효율적인 정상 학습과 구별되지 않지만, 합쳐지면 송전망의 전기기계적 진동 대역(10Hz 미만)에 MW급 강제 진동을 만듭니다. 저자들은 실측 전력 파형으로 시설 모델을 만들고 소신호, 대신호, 플로케(Floquet) 분석으로 계통 영향을 평가한 뒤, 작업별 신호 에너지 기여도로 원인 작업을 찾아내고 작업 시작 시점을 엇갈리게 재배치해 진동을 상쇄하는 탐지와 완화 기법을 제안했습니다.

### Contribution
- 공격자 능력을 가정하지 않고 하드웨어에서 측정했습니다. RTX PRO 4500 Blackwell GPU를 듀티비 20~80%, 0.2~10Hz로 구동해 약 5Hz까지만 사각파를 충실히 재현할 수 있음을 보이고, 이를 위협 모델의 범위로 삼았습니다.
- 공격자가 없어도 진동이 생길 수 있음을 모델로 보였습니다. 큰 학습 작업 몇 개가 비슷하거나 배수 관계인 주파수를 가지면 위상이 풀리지 않아, 조정되지 않은 시설도 수요가 29% 흔들렸습니다.
- MW급 진동이 발전기의 전력계통 안정화 장치(PSS)와 자동 전압 조정기(AVR) 리미터를 포화시켜 스스로 영향을 키우고, 강제 주파수 근처에 감쇠가 거의 없는 모드를 만든다는 점을 플로케 분석으로 보였습니다.
- 작업별 신호 에너지 기여도(대역 제한 포함)로 진동 책임 작업을 지목하는 탐지와, 작업들을 공통 기본 주파수로 늦춘 뒤 좌표 하강법으로 지연을 최적화해 진동 에너지를 최소화하는 완화를 제안했고, 지리적으로 분산된 여러 데이터센터에도 확장했습니다.

### Evaluation
- 상위 20위 슈퍼컴퓨터의 CPU 노드로 1Hz 사각파 부하를 만들자, 같은 변전소를 쓰는 약 1km 떨어진 연구실에서 0.2V 피크 간 전압 진동이 관측됐습니다.
- 수정된 IEEE 68버스 계통에서 평균 420MW 데이터센터를 두고 분석했을 때, 대신호 응답은 G7에서 2.06Hz에 공진하며 소신호 예측보다 약 19dB 컸습니다. 플로케 분석에서는 강제 주파수에 감쇠비 약 0.5%의 모드가 나타났습니다.
- 5,040개 노드(각 50kW)로 쪼갠 시설에서 탐지는 큰 작업 3개의 노드 3,455개를 모두 배경 노드보다 앞에 두어 오지목이 없었습니다. 완화는 100개 작업이 1Hz로 동기화된 경우 RMS 진동을 30.7MW에서 4.6MW로 줄였고 계산에 1.2초가 걸렸습니다.
- 사우디아라비아 송전망 대리 모델(799버스, 발전기 73기)의 전력 하드웨어 인 더 루프(PHIL) 실험에서 계산 노드 20대를 1GW 규모로 확대해 공격을 재현했고, 첫 주기 안에 탐지해 수요 RMS 진동을 199MW에서 31MW(84%), 발전기 주파수 진동을 67mHz에서 20mHz(70%)로 줄였습니다. 두 데이터센터 분산 사례에서는 대상 모선 47개의 전압 진동을 47~76% 줄였고 처리량은 96.8%를 유지했습니다.
- 신빙성: GPU 측정은 GPU 한 장이고, 슈퍼컴퓨터 실험과 PHIL 실험은 모두 GPU가 아닌 CPU 노드로 모델이 만든 파형을 재현했습니다. 계통은 벤치마크와 공개 정보로 만든 대리 모델이며 G7의 관성을 70%로 낮추는 등 영향을 부각하는 설정이 있습니다. 공격 규모가 1GW 이상이라 실제 멀티테넌트 시설의 임대 한도와 신원 확인을 넘을 수 있는지는 실증되지 않았습니다.

#### Comment
- 클라우드 임대를 "부하 변조 공격"의 수단으로 본 점이 새롭습니다. 기존 부하 변조 공격은 에어컨 같은 분산 기기를 대량으로 장악해야 했지만, 여기서는 돈으로 부하를 사면 된다는 주장입니다.
- 완화 기법은 공격과 자연 발생 진동을 구별하지 않고 둘 다 줄인다는 점이 실용적이며, 운영자가 학습 의도를 사전 신고받고 위반을 검증하는 정책도 제안했습니다. 코드나 데이터 공개 주소는 본문에 없습니다.
- 본문에 소속이 적혀 있지 않습니다. 사우디아라비아 송전망을 사례로 쓰고 연구실이 상위 20위 슈퍼컴퓨터와 같은 변전소에 있다고 밝힌 점, 그리고 웹 검색으로 마지막 저자 Charalambos Konstantinou가 KAUST(킹압둘라 과학기술대학교) 교수임을 확인한 점으로 보아 KAUST 연구진으로 보입니다. 나머지 저자의 소속은 확인하지 못했고, 중국 기관 소속이라는 정황은 없습니다.
