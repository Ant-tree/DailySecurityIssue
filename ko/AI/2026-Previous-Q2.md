# CURE: Privacy-Preserving Split Learning Done Right
> PoPETs 2026 Issue 2 (Privacy Enhancing Technologies Symposium), 저널형 학회
> 2026

분할 학습(Split Learning)은 모델 계층을 클라이언트와 서버로 나눠 분산 학습하는 틀로, 서버가 전체 파라미터를 보지 못해 프라이버시 위험을 줄입니다. 그러나 서버와 클라이언트가 주고받는 중간 출력이 클라이언트 데이터의 프라이버시를 깰 수 있고, 동형암호(HE) 기반 해법은 연산 부담이 큽니다. CURE는 단일 클라이언트 환경에서 서버 쪽 모델만(선택적으로 데이터도) 암호화하는 HE 기반 시스템으로, 통신과 병렬화를 크게 개선합니다.

원문: https://petsymposium.org/popets/2026/popets-2026-0047.pdf

### Contribution
- 단일 서버·단일 클라이언트 환경에서 라벨과 (선택적) 데이터의 기밀성을 HE로 보장하는 분할 학습 시스템 CURE를 제안했습니다.
- 효율적 연산을 위한 패킹 기법 두 가지를 제안하고 다층 서버 연산으로 일반화해, 암호화 상태에서 ResNet 블록까지 평가했습니다.
- 서버와 클라이언트 자원에 맞춰 최적 분할 지점을 추천하는 추정기를 처음으로 구현했습니다.

### Evaluation
- 평문 분할 학습과 비슷한 정확도를 유지하면서, 최신 프라이버시 보존 대안 대비 실행 시간이 최대 210배 빨랐다고 보고합니다.
- 공개 코드와 HE 연산용 공개 API를 제공해 재현과 확장이 가능합니다.
- 단일 클라이언트 설정에 초점을 맞추므로 다자간 환경으로의 확장은 별도 과제입니다.

#### Comment
- 엣지-클라우드 분할 추론·학습에서 중간 출력 유출을 HE로 막되 실용 지연을 지키는 설계는, 온디바이스 LLM과 분할 추론 보안에 직접적인 참고가 됩니다.
- 튀르키예 코치대와 빌켄트대 공동 연구이며, 공개 PDF와 GitHub 코드를 갖춘 PoPETs 게재 논문입니다.

# Privacy Bias in Language Models: A Contextual Integrity-based Auditing Metric
> PoPETs 2026 Issue 2 (Privacy Enhancing Technologies Symposium), 저널형 학회
> 2026

LLM이 사회기술 시스템에 통합되면서 모델이 드러내는 프라이버시 편향을 살필 필요가 커졌습니다. 이 논문은 맥락 무결성(Contextual Integrity, CI) 이론에 기반해 "프라이버시 편향"을 LLM 응답 속 정보 흐름의 적절성 값으로 정의합니다. 이 편향과 기대값의 차이(프라이버시 편향 델타)는 프라이버시 침해를 가리킬 수 있고, 모델 학습자, 서비스 제공자, 정책 입안자가 LLM 챗봇과 에이전트를 감사하는 데 쓸 수 있습니다.

원문: https://petsymposium.org/popets/2026/popets-2026-0062.pdf

### Contribution
- 기존 LLM 프라이버시 평가가 데이터 최소화나 특정 범주 보호를 CI와 혼동한다는 문제를 지적하고, CI 원칙에 충실한 감사 지표를 정의합니다.
- 프롬프트 변형에 따른 응답 민감도를 고려해 여러 LLM의 응답을 평가하는 방법을 제시합니다.

### Evaluation
- 여러 LLM의 응답을 맥락 무결성 기반 방법으로 평가하고, 프롬프트 변형 전반에서의 민감도를 반영했습니다. 공개 PDF로 방법론을 확인할 수 있습니다.
- 지표가 "적절성"이라는 규범적 판단에 기대므로, 기대값 설정에 따라 해석이 달라질 수 있다는 점은 저자들도 전제로 둡니다.

#### Comment
- LLM 기반 챗봇·에이전트가 상황에 맞지 않게 정보를 흘리는지를 규범적으로 감사하는 틀은, 온디바이스 어시스턴트의 프라이버시 평가 설계에 참고가 됩니다.
- 요크대와 워털루대 공동 연구이며 PoPETs 게재 논문입니다.
