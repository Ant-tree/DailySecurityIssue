# ACE: A Security Architecture for LLM-Integrated App Systems
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

LLM이 외부 앱을 호출해 사용자 질의에 답하는 통합 앱 시스템은 계획과 실행을 번갈아 수행하는데, 이 과정에서 악성 앱이 계획이나 실행의 무결성을 깨거나 가용성과 프라이버시를 침해할 수 있습니다. ACE는 계획을 두 단계로 분리합니다. 먼저 신뢰할 수 있는 정보만으로 추상 실행 계획을 세우고, 그 다음 설치된 앱에 매핑해 구체 계획을 만듭니다. 구조화된 계획 출력에 정적 분석을 적용해 사용자가 지정한 정보 흐름 제약을 만족하는지 검증하고, 실행 중에는 앱 사이에 데이터와 권한 장벽을 세웁니다.

원문: https://www.ndss-symposium.org/ndss-paper/ace-a-security-architecture-for-llm-integrated-app-systems/

### Contribution
- 기존 방어책 IsolateGPT의 계획 무결성과 실행 무결성, 가용성을 깨는 새로운 공격 세 가지를 제시했습니다.
- 신뢰 구성 요소만으로 계획을 세우면 강력한 보안 정책을 정적으로 강제할 수 있다는 착안을 바탕으로, 설계 단계부터 보안을 갖춘 구조 ACE를 제안했습니다.
- 앱 출력을 LLM의 제어 흐름이 아니라 스키마에 정의된 데이터로만 다뤄 간접 프롬프트 주입이 제어를 탈취하지 못하게 합니다.

### Evaluation
- GPT-4o, o3-mini, GPT-4.1, Claude 3.7 Sonnet, Qwen-2.5-72B를 기반 모델로 써서, INJECAGENT와 Agent Security Bench의 간접 프롬프트 주입 공격과 새로 제시한 공격을 모두 막아 냈다고 보고합니다.
- LangChain Tool Usage 벤치마크로 실제 환경 유용성을 평가해 80% 이상을 유지했습니다.
- 평가가 두 벤치마크와 자체 공격에 한정되므로, 방어가 모든 주입 변종을 막는다는 일반화는 추가 검증이 필요합니다.

#### Comment
- 추상 계획을 신뢰 정보로만 세우고 앱 출력을 데이터로만 취급한다는 설계 원칙은, 온디바이스 에이전트나 앱 연동형 보안 제품을 설계할 때 참고할 만합니다.
- 노스이스턴대 연구진(Alina Oprea, Cristina Nita-Rotaru)의 논문이며 코드가 GitHub에 공개돼 있습니다. NDSS 게재 논문입니다.

# Attention is All You Need to Defend Against Indirect Prompt Injection Attacks in LLMs
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

웹 에이전트나 이메일 비서처럼 외부 데이터를 가져와 쓰는 LLM 애플리케이션은 간접 프롬프트 주입에 취약합니다. 외부 데이터에 심긴 명령이 모델을 조종해 공격자가 원하는 행동을 시키는 것입니다. RENNERVATE는 이를 탐지하고 막는 방어 프레임워크로, 어텐션 특징을 활용해 토큰 단위로 은닉된 주입을 찾아내고 해당 부분만 정제해 기능은 유지하면서 공격을 무력화합니다. 어텐션 헤드와 응답 토큰을 두 단계로 모으는 어텐티브 풀링으로 토큰 수준 탐지기를 구성합니다.

원문: https://www.ndss-symposium.org/ndss-paper/attention-is-all-you-need-to-defend-against-indirect-prompt-injection-attacks-in-llms/

### Contribution
- 어텐션 특징을 이용한 토큰 수준 주입 탐지와 정제 기법을 제안해, 높은 정밀도와 전이성, 작은 파라미터 규모를 동시에 달성합니다.
- 긴 연속 주입 토큰을 공격 신호로 보는 식별 알고리즘을 설계했습니다.
- 5가지 주입 기법과 300개 NLP 과제를 담은 10만 개 규모의 세분화 라벨 데이터셋 FIPI를 구축해 공개하기로 했습니다.

### Evaluation
- ChatGLM, Dolly, Falcon, LLaMA2, LLaMA3 등 구조가 다른 5개 모델과 6개 데이터셋에서, 상용 및 학술 방어 15종을 능가하는 정밀도를 보고합니다.
- 처음 보는 공격에 대한 전이성과 적응형 공격자에 대한 강건성도 함께 보였습니다.
- 평가 모델이 공개 가중치 LLM 위주라 상용 폐쇄형 모델에서의 효과는 별도 확인이 필요합니다.

#### Comment
- 어텐션 신호를 방어에 쓰는 접근은, 온디바이스 LLM이 외부 데이터를 다룰 때의 주입 방어 설계에 참고가 됩니다.
- 중국 기관 검증: 저장대 천옌자오, 쉬원위안 교수 연구실의 논문으로, 이 연구실은 보안 분야 최상위 학회 실적이 꾸준합니다. 15종 기존 방어와의 비교가 구체적이고 데이터셋을 공개하기로 해 재현 가능성이 있으며, 수치가 특정 모델에 유리하게 편중되지 않아 포함했습니다.

# NeuroStrike: Neuron-Level Attacks on Aligned LLMs
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

안전 정렬은 LLM이 유해한 출력을 피하도록 이끌지만, 지도 미세조정이나 인간 피드백 강화학습 기반 정렬은 취약해 공들인 적대적 프롬프트에 뚫릴 수 있습니다. 이 논문은 정렬이 유해 입력을 감지하고 억제하는 역할을 소수의 특화된 "안전 뉴런"에 의존한다는 근본 취약점을 지적합니다. NeuroStrike는 화이트박스에서는 피드포워드 활성 분석으로 안전 뉴런을 찾아 추론 시 제거하고, 블랙박스에서는 공개 가중치 대리 모델에서 학습한 공격 프롬프트 생성기의 전이성을 이용합니다. 이는 방어 관점의 취약점 분석 연구입니다.

원문: https://www.ndss-symposium.org/ndss-paper/neurostrike-neuron-level-attacks-on-aligned-llms/

### Contribution
- 안전 정렬이 희소하고 특화된 안전 뉴런에 의존한다는 공통 취약점을 규명하고, 이를 일반화 가능한 공격 틀로 정식화했습니다.
- 화이트박스 뉴런 제거와, 대리 모델에서 학습한 프롬프트 생성기를 쓰는 블랙박스 프로파일링 공격을 함께 제시했습니다.
- 안전 뉴런이 모델 변종 사이에서 전이된다는 점을 보여, 미세조정 및 증류 모델로도 공격이 이어짐을 확인했습니다.

### Evaluation
- Meta, Google, Alibaba, DeepSeek, Microsoft의 공개 가중치 LLM 20여 종을 평가해, 대상 계층 뉴런의 0.6% 미만 제거만으로 평균 공격 성공률이 12.1%에서 76.9%로 올랐다고 보고합니다.
- 멀티모달 모델 4종의 유해 이미지 입력에 대해 100% 성공률, 블랙박스 모델 5종(제미나이 계열 포함)에서 평균 63.7%를 보고합니다.
- 공격 성공률 판정은 유해 출력 분류에 의존하므로 지표 해석에 분류 기준의 영향이 있고, 방어가 적용된 환경에서의 결과는 별도 절에서 다룹니다.

#### Comment
- 정렬이 소수 뉴런에 집중돼 있다는 분석은 방어 설계에 중요한 시사점을 주며, 온디바이스 공개 가중치 모델을 다루는 입장에서 정렬의 견고성 한계를 보여 줍니다. 구체적 공격 재현 절차가 아니라 취약점의 존재와 원리를 다루는 수준으로 정리했습니다.
- 독일 다름슈타트공대(Ahmad-Reza Sadeghi)와 자그레브대, 라드바우드대 공동 연구이며 NDSS 게재 논문입니다.

# Shadow in the Cache: Unveiling and Mitigating Privacy Risks of KV-cache in LLM Inference
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

KV 캐시는 어텐션의 키-값 쌍을 저장해 LLM 추론을 가속하는 기본 메커니즘입니다. 그런데 사용자와 서버 사이 통신은 암호화되더라도 KV 캐시는 평문으로 전송되고 저장되는 경우가 많아, 이 논문은 공격자가 KV 캐시만으로 사용자 입력을 복원할 수 있음을 처음으로 종합 분석합니다. 모델 가중치를 아는 역산 공격, 후보 입력의 캐시를 비교하는 충돌 공격, 지시 실행 능력을 악용하는 주입 공격 세 가지를 설계하고, 이에 대응하는 경량 방어 KV-Cloak을 제안합니다. KV-Cloak은 가역 행렬 기반 난독화와 연산자 융합으로 캐시를 보호합니다.

원문: https://www.ndss-symposium.org/ndss-paper/shadow-in-the-cache-unveiling-and-mitigating-privacy-risks-of-kv-cache-in-llm-inference/

### Contribution
- KV 캐시의 프라이버시 위험을 역산, 충돌, 주입 세 공격으로 체계적으로 드러냈습니다. 특히 충돌 공격은 역산이 필요 없어 적용 범위가 넓습니다.
- 모델 정확도 저하 없이 적은 오버헤드로 캐시를 보호하는 가역 행렬 난독화 방어 KV-Cloak을 제안했습니다.

### Evaluation
- 세 공격의 복원 품질과 방어 적용 후 품질을 함께 측정해, KV-Cloak이 복원 결과를 사실상 무작위 잡음 수준으로 떨어뜨린다고 보고합니다.
- 방어 적용 시 모델 정확도 저하가 거의 없고 성능 오버헤드가 작다고 제시합니다.
- 공격과 방어를 같은 저자가 함께 평가하므로, 방어의 강건성은 독립적인 적응형 공격으로 추가 검증될 필요가 있습니다.

#### Comment
- KV 캐시를 외부로 전송하거나 공유하는 추론 서빙 구조에서 입력 프라이버시가 깨질 수 있다는 점은, 온디바이스 또는 엣지-클라우드 분할 LLM을 다루는 입장에서 직접적인 함의가 있습니다.
- 중국 기관 검증: 저장대 블록체인·데이터보안 국가중점연구실과 화웨이 공동 연구입니다. 이 연구실은 프라이버시 공격 분야 최상위 학회 실적이 꾸준하고, 공격과 방어를 모두 실측으로 제시하며 수치가 특정 조건에 치우치지 않아 포함했습니다. 다만 코드 공개 링크는 확인되지 않습니다.

# SAGA: A Security Architecture for Governing AI Agentic Systems
> NDSS 2026 (Network and Distributed System Security Symposium), 2026년 2월 발표
> 2026

LLM 기반 에이전트가 서로 협업하고 작업을 위임하며 자율적으로 상호작용하는 환경이 늘고 있습니다. 기존의 에이전트 신원, 인가, 위임 설계는 대체로 이론에 머물렀고 사용자가 자기 에이전트를 통제하는 수단을 제공하지 못했습니다. SAGA는 사용자가 에이전트의 생애주기를 감독할 수 있게 하는 보안 구조로, 사용자가 중앙 제공자(Provider)에 에이전트를 등록하면 제공자가 연락 정보와 사용자 정의 접근 제어 정책을 관리하고 에이전트 간 통신에서 이를 강제하도록 돕습니다. 접근 제어 토큰을 유도하는 암호 메커니즘으로 에이전트 간 상호작용을 세밀하게 통제합니다.

원문: https://www.ndss-symposium.org/ndss-paper/saga-a-security-architecture-for-governing-ai-agentic-systems/

### Contribution
- 사용자가 자기 LLM 에이전트를 통제하고 감독할 수 있는 보안 구조를 제안하고, 공유 키로 암호화된 접근 제어 토큰으로 에이전트 간 통신을 세밀하게 제어합니다.
- 토큰 비밀성, 에이전트와 제공자 간 인증, 임의 두 에이전트 간 인증을 ProVerif로 형식화하고, 메시지를 관찰·가로채기·변조·재전송할 수 있는 공격자에 대해 자동 증명했습니다.

### Evaluation
- 회의 일정 조율, 경비 보고서 제출, 공동 작성 같은 여러 에이전트 작업을, 서로 다른 지역에 둔 에이전트와 온디바이스 및 클라우드 LLM 여러 종으로 평가했습니다.
- 다양한 조건에서 작업 유용성 저하 없이 최소 오버헤드를 보였다고 보고하며, 코드를 GitHub에 공개했습니다.
- 중앙 제공자에 신뢰를 집중하는 구조이므로, 제공자 자체가 손상된 경우의 위협은 설계 전제를 벗어납니다.

#### Comment
- 에이전트 간 통신에 사용자 제어 접근 정책을 암호학적으로 강제한다는 설계는, 온디바이스 에이전트가 외부 에이전트와 상호작용할 때의 보안 모델 참고 자료로 유용합니다.
- 노스이스턴대 연구진(Cristina Nita-Rotaru, Alina Oprea)의 논문이며 형식 증명과 공개 코드를 갖춘 NDSS 게재 논문입니다.
