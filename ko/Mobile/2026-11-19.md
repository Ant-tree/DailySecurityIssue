세부 분류: 온디바이스 LLM (4비트 양자화와 거부 행동)

# Is 4-Bit Quantization More Than Noise to a Chat Model's Safety Behaviour? Attributing Behavioural Shifts with Matched Perturbations
> arXiv 프리프린트 (심사 전), 코드와 라벨 공개. 브리티시컬럼비아 대학교
> 2026

휴대폰과 노트북에서 돌아가는 채팅 모델은 대부분 평가를 거친 원본이 아니라, 제3자가 명령 한 줄로 만든 4비트 사본입니다. 성능은 확인하지만 같은 요청을 여전히 거부하는지는 그냥 믿고 넘어가는 경우가 많고, 기존 감사 연구들도 4비트 양자화가 거부를 줄인다, 거의 바꾸지 않는다, 오히려 늘린다로 결론이 엇갈렸습니다. 저자는 4비트 빌드가 "같은 크기의 수많은 가중치 교란 가운데 하나"라는 점에 주목해, 행동 변화가 양자화 고유의 반올림 오차 때문인지, 아니면 그 정도 크기의 아무 교란이면 생기는 일인지를 가려내는 사전 등록 실험을 설계했습니다. 3~4B 모델 세 개(Qwen2.5-3B, Llama-3.2-3B, Qwen3-4B)에 대해, 순응 답변 앞부분을 미리 채워 넣는 "강제 시작"과 실제 탈옥 프롬프트를 그대로 주는 "자유 시작" 두 조건으로 비교했고, 실제 오차를 섞거나 같은 크기의 가우스 오차로 바꾸거나 크기를 조절한 대조 교란을 함께 만들었습니다.

### Contribution
- 양자화 오차와 크기가 같은 "양자화가 아닌" 교란(섞은 오차, 가우스 오차, 실제 오차의 배율 조정)을 대조군으로 써서, 거부 행동 변화의 원인을 오차의 구조와 크기로 나눠 보는 실험 설계를 제시했습니다.
- 텍스트가 대부분 바뀌어도 우도는 그대로인 8비트 빌드를 "변화 없음" 기준으로 두고, 모든 결과를 원본과 짝지은 비율 차이로 보고해 라벨 불안정성을 통제했습니다.
- 4비트 거부 행동 변화는 비트 수나 우도가 아니라 특정 반올림 오차에 달려 있으므로, 빌드마다 원본과 따로 비교해야 한다는 실무 결론을 냈습니다.
- 코드, 사전 등록 문서, 판정 모델과 사람 라벨을 모두 공개했습니다.

### Evaluation
- 결과: 서로 부호가 반대인 두 변화가 나왔습니다. 강제 시작에서 4비트 Qwen2.5-3B는 유해한 답변을 원본보다 더 자주 이어 썼고, 자유 시작에서 4비트 Llama-3.2-3B는 보류된 탈옥 프롬프트에 원본보다 10.3%p 덜 순응했습니다. Qwen3-4B는 두 조건 모두 유의한 변화가 없었습니다.
- 대조 교란: 섞은 오차와 가우스 오차는 평균적으로 0에 가까운 변화만 냈고, 실제 오차를 거울상(-1배)에서 2배까지 조절하면 행동이 거의 선형으로 바뀌었습니다. 실제 오차의 절반만 넣어도 Llama는 우도가 거의 그대로인데 이미 5.8%p 덜 순응했습니다. 같은 비트 수인 llama.cpp Q4_K_M은 두 모델 모두 움직이지 않았습니다.
- Llama의 거부 증가는 판별력이 좋아진 것이 아니라, 탈옥처럼 쓰인 정상 요청까지 더 많이 거부한 결과였습니다.
- 신빙성: 대응 검정, 블라인드 사람 라벨, 8비트 기준을 갖춘 사전 등록 연구라 설계가 탄탄합니다. 다만 저자 스스로 밝히듯 대상이 두 회사의 3~4B 모델 세 개뿐이고, 답변을 128토큰에서 잘라 판정했으며, 같은 대비에서 판정 모델은 +6.2%p, 사람 라벨은 +19.4%p로 효과 크기가 크게 달랐습니다(부호는 같음). imatrix GGUF, bitsandbytes, 양자화 인식 학습 같은 다른 구현은 다루지 않았습니다.

#### Comment
- 온디바이스 LLM의 안전성을 "원본 모델이 안전하면 사본도 안전하다"로 가정하면 안 된다는 점을 통제된 방법으로 보여 준 연구입니다. 같은 4비트라도 양자화 도구에 따라 결과가 달랐다는 점은 기기 배포 단계에서 빌드별 안전성 회귀 시험이 필요하다는 근거가 됩니다.
- 단일 저자 연구이며, 결과가 모델마다 반대 방향으로 나와 "4비트 양자화가 안전성을 낮춘다"는 일반 결론으로 읽어서는 안 된다고 저자가 분명히 적었습니다.
