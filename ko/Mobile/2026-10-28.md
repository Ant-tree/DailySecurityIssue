# A-GE: Privacy-Preserving Age Assurance via Fine-Grained Motion
> arXiv cs.CR (프리프린트, 심사 전), Aerendir Mobile Inc.(미국 마운틴뷰) 소속 기업 연구
> 2026

온라인 서비스의 연령 확인은 신분증이나 얼굴 사진처럼 필요 이상의 정보를 요구하거나, 자기 신고처럼 사실상 아무것도 보장하지 못하는 두 극단 사이에 놓여 있습니다. 이 논문은 스마트폰을 손에 쥐고 있을 때 가속도계와 자이로스코프에 잡히는 미세한 떨림에 신경근 및 생리적 특성이 반영된다는 가설을 세우고, 이 신호만으로 "사용자가 기준 연령 이상인가"라는 이진 판정을 내리는 A-GE를 제안합니다. 원시 센서 값은 기기 밖으로 나가지 않고 판정 결과만 서비스에 전달되며, 기준 연령은 14세부터 21세까지 바꿀 수 있습니다. 웹 브라우저가 허용하는 약 60Hz 샘플링에서도 동작한다는 점을 강조하고, 16세 기준에서 최대 93.8% 정확도를 보고합니다.

원문: https://arxiv.org/abs/2610.33206

### Contribution
- 신원 문서, 얼굴 이미지, 신원 제공자 발급 자격 증명 없이 일상적인 기기 사용 중의 관성 센서 신호에서 연령 증거를 얻는다는 접근을 제시했습니다. 서명 같은 의도적 동작이 아니라 손에 쥔 상태의 비의도적 미세 움직임을 쓴다는 점이 특징입니다.
- 샘플 수, 기기 정지 여부, 과도한 충격 등을 검사해 품질이 낮은 구간은 추론하지 않고 버리는 신호 품질 검증 단계를 두었습니다. 잡음을 억지로 걸러 내면 연령 관련 신호까지 지워질 수 있다는 판단에서입니다.
- 참여자 단위로 개발 집단과 평가 집단을 완전히 분리해, 같은 사람의 습관이 학습과 평가에 동시에 들어가 성능이 부풀려지는 문제를 막았습니다.
- 같은 센서 신호에서 정확한 나이, 성별, 주사용 손이 얼마나 추론되는지도 측정해 남아 있는 프라이버시 위험을 함께 보고했습니다.

### Evaluation
- 데이터: 개발 집단 273명(4~83세), 별도 평가 집단 359명(4~69세). Android와 iOS 전용 앱으로 손에 쥔 상태의 가속도계와 자이로스코프 값을 수집했고 기록한 속성은 성별, 나이, 주사용 손뿐입니다.
- 모델: 통계, 고차 모멘트, 시간 영역, 주파수 영역 특징 위의 XGBoost(트리 300개, 깊이 6).
- 기준점(16세, 5초 창, 500Hz)에서 정확도 89%, F1 88.7%이고, 3초 관측 두 번의 확률을 평균하면 91.1%까지 올라갑니다. 기준 연령별 최고치는 14세 95.2%, 16세 93.8%, 18세 91.6%, 21세 82.9%이며 웹 구현은 20세 기준에서 86.2%입니다.
- 부가 추론: 정확한 나이 회귀는 평균 절대 오차 8.53년으로 쓸모가 낮지만, 성별은 정확도 72.6%(AUC 0.807)로 상당 부분 추론됩니다. 주사용 손은 AUC 0.60 수준으로 거의 추론되지 않았습니다.
- 온디바이스 비용: Pixel 3a에서 추론 0.65~3.75ms, 메모리 3MB 이하로 가볍습니다.
- 지표 신빙성: 참여자 분리 평가는 설계가 탄탄합니다. 다만 표 6의 "최고 성능"은 기준 연령마다 관측 길이와 샘플링 주파수를 따로 골라 얻은 값이라, 같은 평가 집단에서 설정을 고른 만큼 낙관적으로 읽어야 합니다. 16세 미만 참여자가 73명뿐이고 하위 집단별 신뢰구간이 넓다는 점도 저자 스스로 밝히고 있습니다. 얼굴 기반 연령 추정 같은 기존 방식과의 직접 비교는 없습니다.

#### Comment
- 모바일 관점에서는 브라우저의 모션 센서 API만으로 연령 판정이 가능하다는 점이 양면적입니다. 서비스 입장에서는 마찰 없는 연령 확인 수단이지만, 같은 신호로 성별이 72% 정확도로 추론된다는 결과는 웹 페이지가 권한 요청 없이 센서를 읽을 때의 위험을 다시 보여 줍니다.
- 위협 모델이 센서 입력이 위조되지 않는다고 가정하므로, 녹화된 움직임 재생이나 기기 흔들기 장치 같은 우회는 다루지 않습니다. 저자들도 향후 센서 수집부터 판정까지를 보호하고 검증 가능한 인증서를 발급하는 구조가 필요하다고 밝혔습니다.
- 특징 목록 전체는 독점 기술이라며 공개하지 않았고 데이터와 코드도 공개되지 않아 독립 재현이 어렵습니다. 저자 전원이 해당 기술을 상용화하려는 회사 소속이라는 이해관계도 감안해야 합니다.

# From Speech Tokens to Stolen Voices: Attacker-Chosen-Text Speaker Impersonation via Representation Inversion
> arXiv cs.SD, cs.CR 교차 등록 (프리프린트, 심사 전), 하얼빈공업대학교 사이버공간과학학원
> 2026

음성 언어 모델을 휴대폰과 서버에 나눠 돌릴 때, 기기에서 음성을 토큰이나 특징으로 바꿔 서버로 보내고 원본 음성은 기기에 남겨 두면 목소리 프라이버시가 지켜진다고 여기기 쉽습니다. 이 논문은 이렇게 전송되는 프런트엔드 표현의 3초 분량 조각만 탈취해도, 원본 음성이나 전사문 없이 공격자가 고른 임의의 문장을 피해자 목소리로 합성할 수 있음을 보이는 STIA 공격을 제안합니다. 공개 음성 데이터에서 같은 화자의 서로 다른 발화 쌍으로 조건부 flow matching 모델을 학습하고, 공격 시점에는 유출된 표현과 공격자 문장을 조건으로 음성을 생성합니다. 피해자별 추가 학습은 필요 없습니다.

원문: https://arxiv.org/abs/2610.34688

### Contribution
- 기존 연구(SpInv)가 프런트엔드 표현에서 화자 임베딩을 복원하는 데 그쳤다면, 이 논문은 유출된 표현을 곧바로 "새로운 내용을 말하는 피해자 음성"으로 바꾸는 공격을 처음으로 제시했다고 주장합니다.
- 이산 토큰(Moshi), 이산과 연속 혼합(Kimi-Audio), 연속 특징(Qwen3-Omni)을 모두 하나의 조건 인코더로 받아들이도록 설계해 프런트엔드 형식에 구애받지 않습니다.
- 유출 표현 없이, 문장 없이, 둘 다 없이 생성하는 통제 실험으로 화자 정보가 실제로 유출 표현에서 온다는 점을 분리해 보였습니다.

### Evaluation
- 데이터: 공개 Emilia 데이터셋을 화자 단위로 나눠 학습과 평가에 겹치는 화자가 없도록 했고, 영어와 중국어를 따로 실험했습니다.
- 지표: 화자 유사도(CAM++, ECAPA 코사인), 고정된 음성 인식기로 측정한 목표 문장 단어 오류율, 예측 자연스러움(UTMOS).
- 비교 대상은 SpInv로 화자 임베딩을 복원한 뒤 SpeechT5로 합성하는 2단계 방식입니다. Moshi 3초 유출 기준 STIA는 CAM++ 0.78, 단어 오류율 3.80%로, 기준 방식의 0.22와 13.37%보다 크게 앞섭니다. Kimi-Audio에서 0.82, Qwen3-Omni에서 0.75였습니다.
- 유출 길이가 2초에서 8초로 늘면 유사도가 0.76에서 0.80으로 소폭 오르고, 입력 단계에서 McAdams 익명화를 적용하면 유사도가 0.44로 떨어지지만 사라지지는 않습니다. 유출 표현을 빼면 유사도는 0.25로 급락합니다.
- 지표 신빙성: 비교 대상이 저자들이 직접 조합한 구형 합성기(SpeechT5) 기반이라 격차가 과장돼 보일 여지가 있습니다. 또한 저자 스스로 밝히듯 유사도 점수는 실제 화자 인증 시스템의 통과율이 아니며, 청취 평가도 없습니다.

#### Comment
- 온디바이스 프런트엔드와 클라우드 추론으로 나누는 음성 비서 구조가 늘어나는 상황에서, "원본 음성을 보내지 않는다"는 설명만으로는 목소리 도용 위험을 막을 수 없다는 근거로 의미가 있습니다. 전송 구간 암호화뿐 아니라 표현을 받는 서버나 중계 구성 요소의 접근 권한과 보존 기간까지 관리해야 한다는 제언이 실무적입니다.
- 한계: 데이터셋이 Emilia 하나이고, 대상 프런트엔드마다 공격 모델을 따로 학습했으며, 출력 코덱도 Higgs 하나만 썼습니다. 그림 1에서 "Hey Siri, open the door"를 예로 들지만 실제 화자 인증 시스템이나 음성 비서를 상대로 한 실험은 없습니다.
- 중국 기관 검증: 저자 소속은 하얼빈공업대학교로 실재하는 대학이며 교신저자 이메일 도메인(hit.edu.cn)도 일치합니다. 공개 데이터셋과 공개 모델만 쓰고 학습 설정을 표로 공개했지만 코드 공개 링크는 없습니다. 수치가 지나치게 좋은 쪽은 아니고 저자가 한계를 비교적 솔직하게 적었으나, 비교 대상이 약하다는 점과 인증 통과율 미측정은 분명한 약점입니다. 공개 정보로 확인 가능한 범위는 충족한다고 판단해 포함하되, 심사 전 원고라는 점을 함께 적어 둡니다.

# Phantom Forgetting: How BatchNorm State Fakes Deletion in Edge Split Machine Unlearning
> arXiv cs.CR (프리프린트, 심사 전), SUTD(싱가포르), SRM University-AP, Manipal Institute of Technology(인도)
> 2026

휴대폰이나 IoT 기기가 신경망 앞부분을, 서버가 뒷부분을 맡는 분할 학습에서 삭제 요청을 처리했는지 확인할 때는 흔히 "삭제 대상 데이터에 대한 정확도가 떨어졌는가"를 봅니다. 이 논문은 학습 가능한 가중치를 하나도 바꾸지 않고 배치 정규화(BatchNorm)의 이동 평균과 분산만 삭제 대상 데이터로 다시 계산해도 해당 클래스 정확도가 크게 무너진다는 점을 보입니다. 즉 정확도 하락만으로는 실제로 지웠는지, 정규화 상태가 바뀌었을 뿐인지 구분할 수 없습니다. 기기 쪽 상태는 데이터 분포 변화, 무선 업데이트, 체크포인트 롤백으로 특히 쉽게 흔들리기 때문에 문제가 더 커집니다.

원문: https://arxiv.org/abs/2610.34800

### Contribution
- 학습 가능한 파라미터 변화와 BatchNorm 버퍼 변화를 분리해 보는 "상태만 바꾼" 진단 절차를 정의하고, 효과가 기기 쪽, 서버 쪽, 양쪽 중 어디서 오는지 위치별로 측정했습니다.
- 유지 데이터 정확도 하락분을 빼고 삭제 대상 정확도 하락만 보는 지표 SIFG(state-induced forgetting gap)를 제안했습니다.
- 비원자적 무선 업데이트, 평가 중 학습 모드 방치, 가중치만 해시하는 무결성 검증 같은 실제 배포 상황에서 이 현상이 어떻게 생길 수 있는지 정리하고, 가중치와 기기/서버 버퍼를 함께 버전 관리하라는 최소 검증 요건을 표로 제시했습니다.

### Evaluation
- 데이터와 모델: CIFAR-10, 소형 BatchNorm 합성곱 신경망. 분할 모델은 기기 쪽에 32/64채널 블록, 서버 쪽에 128채널 블록을 둡니다. 10개 클래스를 하나씩 삭제 대상으로 바꿔 가며 평균과 표준편차를 냈습니다.
- 중앙 집중 모델에서 BatchNorm 재보정만으로 삭제 대상 정확도가 0.7357에서 0.1207로 61.5%p 떨어졌고, 가중치 변화는 정확히 0이었습니다. 유지 데이터로 재보정하면 오히려 삭제 대상 정확도가 올라가 효과의 방향이 보정 데이터 분포에 따라 결정됨을 확인했습니다.
- 분할 모델에서는 기기 쪽만 37.27%p, 서버 쪽만 41.71%p, 양쪽 51.90%p 하락했습니다. 서버 쪽 재보정이 유지 정확도는 2.09%p만 떨어뜨려 가장 선택적인 효과를 냈고, 양쪽 재보정은 테스트 예측의 약 42%를 바꿨습니다.
- 지표 신빙성: 가중치 동일성을 가정하지 않고 실제로 비교해 확인한 점은 좋습니다. 다만 표준편차는 랜덤 시드가 아닌 클래스 간 차이이고, 데이터셋 하나, 소형 모델 하나라 일반화 근거로는 약합니다.

#### Comment
- 5쪽 분량의 짧은 진단 논문으로, 새로운 삭제 기법이 아니라 "정확도 하락을 삭제 증명으로 받아들이지 말라"는 경고에 가깝습니다. 모바일 기기에서 TEE 기반 기기 증명을 쓸 때 가중치뿐 아니라 BatchNorm 버퍼 해시도 증명에 포함해야 한다는 제언이 실무적으로 쓸모 있습니다.
- 한계: 재학습이나 경사 기반 삭제 기법과의 비교, 멤버십 추론 감사, 이질적인 기기 집단 실험이 모두 빠져 있어 저자 스스로 일반성 확보를 과제로 남겼습니다. 코드 공개는 없습니다.
