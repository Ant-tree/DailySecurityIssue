# Consensus-Constrained Dual-Federated Optimization with Client-Side Dynamic Weighting for Distributed Android Device Threat Defense
> arXiv cs.LG 2611.09470 (cs.CR 교차 게재, 프리프린트, 심사 전). 테헤란 대학교(이란), 세종대학교(한국)
> 2026

스마트폰, 스마트홈 허브, 웨어러블에서 Android 악성코드를 탐지하려면 많은 기기의 데이터가 필요하지만, 원본 데이터를 한곳에 모으면 개인정보와 확장성 문제가 생깁니다. 연합 학습은 데이터를 모으지 않고 함께 학습할 수 있게 해 주지만, 일부 기기만 학습에 참여하거나 기기별 모델 품질이 다르면 전역 최적화가 불안정해집니다. 이 논문은 원-쌍대(primal-dual) 조정 방식인 FedADMM에, 각 클라이언트의 성능에 따라 로컬 상태의 반영 비중을 조절하는 동적 가중치를 더한 DW-FedADMM을 제안합니다. 쌍대 변수는 로컬과 전역 모델의 불일치를 조절하고, 동적 계수는 증강 라그랑지안 갱신 전에 각 클라이언트의 로컬 상태를 조정합니다.

### Contribution
- 합의 제약 기반 원-쌍대 연합 최적화와 성능 의존 동적 가중치를 결합한 최적화 방법을 제시했습니다.
- 같은 동적 가중치를 FedAvg, FedProx에 붙인 변형(DW-FedAvg, DW-FedProx)까지 포함해 다섯 가지 연합 학습 기준선과 동일한 코드 기반에서 비교했습니다.

### Evaluation
- 데이터: 공개 Android 악성코드 벤치마크 Drebin, Malgenome(각 215개 특징), TUANDROMD(4,465개 앱, 241개 특징)의 전처리된 특징 표현을 그대로 썼습니다.
- 설정: 은닉층 200, 100, 50개의 4층 순전파 신경망을 모든 방법에 동일하게 쓰고, 80:20 분할 뒤 학습 데이터를 클라이언트 5, 10, 15개에 균등하게(IID) 나눴습니다. 부분 참여, 통신 5회와 10회 예산, 조건마다 난수 시드 10개로 반복했습니다.
- 결과: Drebin에서 시드 평균 정확도 97.64%(표준편차 0.20%)로 가장 높았고, 18개 조건 중 9개에서 평균 정확도 1위였습니다(통신 10회 조건에서는 9개 중 7개). 전체 조건을 합치면 정확도 95.42%, F1 94.62%, 정밀도 96.06%, AUC 99.45%로, FedADMM(95.32%, 94.51%, 95.56%, 99.41%)보다 조금 높고 평균 오탐률은 가장 낮았습니다.
- 지표의 신빙성: 시드 10개 반복과 동일 코드 기반 비교는 좋은 관행입니다. 다만 FedADMM과의 차이가 0.1%포인트 수준으로 작아 실질적인 우위로 보기 어렵고, 데이터를 IID로 나눠 연합 학습의 핵심 난제인 기기별 데이터 이질성은 평가하지 않았습니다(저자들도 다음 과제로 언급). Drebin, Malgenome은 오래된 데이터셋이라 최신 악성코드 환경을 대표하지 못합니다.
